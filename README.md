# ShortPath_Boston Area
# This project focuses on the relationship between air quality and the environment of public schools in the Boston metropolitan area. The study aims to identify features affecting # student health by analyzing air pollution data and school geographic distribution. It uses a method that calculates the shortest path from a centroid to each school, with path 
# length and PM2.5 levels weighted. The findings aim to guide urban planning initiatives by providing data-driven recommendations for improving school environments and air quality.
